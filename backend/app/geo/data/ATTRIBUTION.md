# Nepal birthplace data

Derived from [GeoNames](https://www.geonames.org/) and redistributed under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
The source is the [Nepal country export](https://download.geonames.org/export/dump/NP.zip)
dated 2026-11-27, SHA-256
`d46b480c53e30f68800474f4dabd8eeec2138afbb12bb3fecdfcdfc1815e021a`.
[GeoNames extract documentation](https://download.geonames.org/export/dump/readme.txt)
describes the source fields and license.

Kundali filters populated features, retains Latin and Devanagari source
aliases, joins available administrative names from the same export, and
compresses the resulting table. GeoNames provides the data as is.

Packaged table SHA-256
`2af1796ec45a6c9c6f43d9cc032c2a38a4132b75487c67b345b336b92022f2cd`.
